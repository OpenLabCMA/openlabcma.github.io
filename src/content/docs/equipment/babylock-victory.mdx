## Before you start

1. The blade cuts everything in its path. Keep fingers, pins, and jewelry away.
2. Never sew over pins.

## Quick reference

{/* EDIT: photos of jet-air threading sequence, tension dials, stitch settings chart */}

- Threading order matters: upper looper, lower looper, right needle, left needle.
- The jet-air system threads loopers with the push of a lever; ask for a demo the first time.

## Troubleshooting

| Symptom | First things to try |
|---|---|
| Loops hanging off fabric edge | Check looper threading order and tensions |
| Skipped stitches | New needle (this machine notices dull needles fast) |
| Fabric jams at the blade | Stop; raise the blade; ask for help |
