## Before you start

1. Bring or choose: stabilizer, thread, fabric. Lab stock lives in {/* EDIT: location */} the lab.

## Workflow

1. **Design.** Make or convert a design to `.dst` or `.pes`. Tools we use: Turtlestitch, InkStitch (Inkscape plugin), Hatch.
2. **Load.** Copy the `.dst` or `.pes` file to a USB stick, plug into the machine, select the design.
3. **Hoop.** Stabilizer under fabric, drum-tight, mounted on the machine.
4. **Thread.** Top thread and bobbin (steps below).
5. **Stitch.** Baste first if the fabric can shift. Stay near the machine.
6. **Finish.** Remove hoop, tear/cut away stabilizer, trim jump stitches.

## Threading

{/* EDIT: replace with our own photo sequence; numbered thread path photos beat any text */}

- Top thread: follow the numbered path printed on the machine, 1 through 7. Presser foot up while threading. Use the automatic needle threader.
- Bobbin: use Brother 11.5 mm class bobbins only. Drop-in; thread through the slit until it clicks, trail out the back.

## Troubleshooting

| Symptom | First things to try |
|---|---|
| Thread breaks repeatedly | Rethread top (foot up), check needle not blunt/bent, slow the machine down |
| Bird's nest under fabric | Be sure to carefully remove all thread from under fabric and inside machine if necessary. Rethread top thread fully; the top thread missing the tension disks causes this, not the bobbin |
| Design not on USB menu | File must be `.dst` or `.pes` at the top level of the stick, FAT32 stick |
| Fabric puckering | More/heavier stabilizer, loosen hooping tension, reduce design density |
| Needle breaks | Stop immediately. Remove all parts of needle. Ask for help if you need it. Rethread |
