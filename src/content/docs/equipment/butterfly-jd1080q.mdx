## Troubleshooting

| Symptom | First things to try |
|---|---|
| Skipped stitches | New needle, correct needle type for fabric |
| Thread bunching underneath | Rethread top with presser foot up |
| Fabric not feeding | Check feed dogs are up, presser foot down |
