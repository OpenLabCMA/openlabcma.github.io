## Before you start

1. Check media and ink cost with the lab manager before large prints. {/* EDIT: cost policy */}

## Workflow

1. Prepare the file: correct dimensions, 300 dpi at print size, embedded color profile.
2. Soft-proof with the paper's ICC profile.
3. Load media (ask for help with roll changes the first time).
4. Print a small test strip before a full-size print.

## Troubleshooting

| Symptom | First things to try |
|---|---|
| Banding | Nozzle check, then head cleaning from the panel |
| Colors wrong | Confirm ICC profile matches the loaded paper |
| Media jam or skew | Stop; ask for help; do not pull |
