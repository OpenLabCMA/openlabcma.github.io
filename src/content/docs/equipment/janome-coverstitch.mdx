## Before you start

1. Coverstitch is not a serger; no blade, no overlock. Use the Victory for seam finishing.

## Quick reference

{/* EDIT: photos: threading, looper, hem guide setup */}

- Chain off at the end of a seam and secure the chain; coverstitch unravels from the end if unsecured.

## Troubleshooting

| Symptom | First things to try |
|---|---|
| Tunneling between needle rows | Loosen looper tension, lighter stabilizing |
| Skipped stitches on seams | Slow down over bulk, try a new needle |
